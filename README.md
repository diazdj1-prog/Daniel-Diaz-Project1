# Daniel-Diaz-Project1
Games, Save File, Data---
My topic is about reverse engineering video game save files in order to achieve certain things in games that would either have to be earned later, or achieve certain things that would be impossible. This matters because it shows how video games store and serialize their data. video games are very complex in nature, video games are running in loops constantly and have to check and save data. Once the user decided to stop playing that data needs to be stored somewhere. This process is very important, otherwise if we didn't have this process people would be constantly loosing their save data. Imagine playing one of your favorite games for quite some time, then imagine all of the progress you made was lost. Without save data people would have to finish their games in one sitting, for most people that's pretty unreasonable especially with the size of modern video games. Seeing how data is stored also allows for mod teams to add their own expansions into games. Understanding how and where data is stored allows for endless possibilities for modding communities, introducing things that are not in the base game, such as character skins or difficulty challenges. The question I hope to answer with this blog is how to access and modify game save data, as well as seeing how data is stored and serialized. After getting enough information about how a game stores data, I will try and modify the game to give myself something that would be otherwise impossible to get at the current stage of the game. Hopefully after this project I will be more educated on how saves work, and potentially make my own video game mods in the future.
